Android Flight UI – Portrait & Landscape
Une application Android simple qui affiche une interface moderne de vols, entièrement adaptée pour les modes portrait et paysage grâce à l’utilisation de layout et layout-land. Le même code Kotlin est utilisé pour les deux orientations, avec un design responsive et professionnel.

🚀 Fonctionnalités :
Interface responsive (portrait & paysage)
Header moderne : date, origine, destination
Visuel du trajet de vol (points, lignes, avion)
Informations sur les passagers
Liste des vols via RecyclerView
Icônes personnalisées (back, edit, plane, person)
Logique Kotlin unique sans duplication
